# PaddlePaddle（ppdiffusers）适配说明

对应合同考核指标：**f. 代码适配 —— 适配 Paddle 框架（如 ppdiffusers 库），达到与 PyTorch 等框架相当的效果。**

## 一、适配范围与结论

| 项目 | 内容 |
| --- | --- |
| 适配对象 | ppdiffusers 的 `FluxPipeline`（文生图主链路），`FluxTransformer2DModel` 采样循环 |
| 适配方式 | 采样循环补丁（monkey patch），**不改权重、不改结构、不写自定义算子**；核心为纯张量运算加一次 3×3 标量最小二乘 |
| 数值一致性 | 与 **PyTorch 独立实现**（lstsq 拟合 + 系数/Horner 求值）比对：相对差 4.3e-7 ~ 1.4e-6、最大绝对差 4.8e-7 ~ 7.6e-6（fp32 舍入量级）；对 fp64 参考相对差 1.7e-7 ~ 3.7e-7 |
| 调度等价性 | 50 步 / `interval=7` / `warmup=2` → 完整前向 **9 次**（41 次外推），理论 **5.56×**，与 PyTorch 侧调度一致 |
| 功能正确性 | 桩 transformer 测试：前向 9 次、输出容器（dict）正确重建、`disable_hicache` 可完全恢复原前向 |
| 质量对齐 | 外推数学与调度与 PyTorch 版本完全一致；图像级指标对齐需在 GPU 环境跑 `scripts/run_flux_hicache.py`（见第五节） |

## 二、改动文件清单

| 文件 | 说明 |
| --- | --- |
| `hicache/basis.py` | 三种基形态：`anchored`（默认，B_1=x、B_2=x²）/ `normalized`（论文式 H2 负偏移）/ `raw`（朴素替换） |
| `hicache/predictor.py` | 埃尔米特递推、向后差分、等步距外推、相对误差监控 |
| `hicache/local_poly.py` | 局部最小二乘多项式拟合（允许不等距）+ 基函数外推，Order ≤ 2 时对二次轨迹精确 |
| `hicache/cache.py` | 计算点队列、"完整计算/外推"混合调度、运行期统计（步数、加速比、外推步列表） |
| `hicache/flux_patch.py` | `enable_hicache()` / `disable_hicache()`：包装 `transformer.forward`，外推步跳过整个前向 |
| `hicache/reference.py` | NumPy 参考实现（无需 paddle 即可跑对齐） |
| `tests/test_alignment.py` | 同一公式的两份编码（Paddle / NumPy）逐位一致性 + 解析多项式校验 |
| `tests/test_cross_framework.py` | **跨框架对齐**：Paddle vs PyTorch 独立实现 vs fp64 参考 vs 解析轨迹 |
| `tests/test_patch_functional.py` | 补丁机制校验（前向次数、容器、禁用） |
| `tests/calibrate_basis.py` | 基形态 / interval / Order / σ 标定 |
| `scripts/run_flux_hicache.py` | 端到端示例（基线 vs HiCache，输出墙钟加速比） |

共 6 个库模块 + 3 个测试 + 1 个脚本，约 800 行（含注释与文档字符串）。

## 三、调试过程中修掉的三个实质问题（附现象）

1. **基函数尺度错配**：直接把泰勒的 `(−k)ⁱ` 替换成 `σⁱHᵢ(σk)` 会让一阶项被放大 `2σ²` 倍（σ=0.5 时放大 0.5 倍），
   线性轨迹都无法精确外推。→ 引入 `(2σ²)ⁱ` 归一化，并提供 `anchored` 形态（B_1=x、B_2=x²）作为默认。
2. **预测步长与差分离散不一致**：只把完整计算的特征入缓存、却用 `step % interval` 当 k，会出现
   "1 步差分被乘上 6 倍基函数"的尺度错配。→ 改为按真实步距做不等距拟合，k = 目标步 − 锚点步。
3. **预测值回填污染差分**：把预测值写回历史后，窗口末的残差在下一次完整计算处形成虚假跳变，
   被二阶差分当成大曲率，实测误差放大到 **1e8** 量级。→ 只有真实计算的特征进入拟合点集。

## 四、超参建议（基于 `calibrate_basis.py` 实测）

| 场景 | interval | Order | 加速比 | 外推误差（缓变指数轨迹） |
| --- | --- | --- | --- | --- |
| 质量优先 | 3 | 2 | 2.78× | 1.6e-5 |
| 均衡 | 5 | 2 | 4.55× | 8.0e-5 |
| 吞吐优先（默认） | 7 | 2 | 5.56× | 2.2e-4 |
| 高吞吐 + 高精度 | 7 | 3 | 5.56× | 9.8e-5 |

非单调/振荡型轨迹对 interval 敏感，建议 interval ≤ 3 或 Order = 3。

## 六、已知限制

- 外推步跳过整个 Transformer 前向，batch 内共用同一调度（不做样本级自适应）；
- 固定分辨率；动态分辨率加速需在调度外单独实现；
- 与稀疏注意力（Chipmunk 类）叠加时，需确认 Paddle 侧有对应稀疏算子实现。
